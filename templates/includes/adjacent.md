## Adjacent redundant links [WCAG 2.4.9](https://www.w3.org/WAI/WCAG21/quickref/?versions=2.0#link-purpose-link-only) [WCAG 4.1.2](https://www.w3.org/WAI/WCAG21/quickref/?versions=2.0#name-role-value)

When adjacent links have different text but go to the same location it makes navigating difficult and confusing since the different text will take them to the same locations. 

Common accessibility issue on websites is when an adjacent image is linked. When a link has an image inside it, the image alt text _becomes_ the link text.
